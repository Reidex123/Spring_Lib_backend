LIBRARY SYSTEM - DTOs AND FIELDS
================================
Naming: XRequest = input to a controller (validated), XResponse = output from a controller.
Entities are never returned directly. passwordHash never appears in any DTO.
Optional fields are marked (optional).


AUTH (AuthController)
---------------------
LoginRequest
  email: String
  password: String

AuthResponse
  userId: long
  firstName: String
  lastName: String
  role: String                  (STUDENT, EMPLOYEE or ADMIN)


CATALOGUE (BookController, AuthorController, CategoryController)
----------------------------------------------------------------
CreateBookRequest
  isbn: String
  title: String
  edition: String
  publisher: String
  publicationYear: int
  authorIds: List<Long>
  categoryId: long

UpdateBookRequest
  title: String
  edition: String
  publisher: String
  publicationYear: int
  authorIds: List<Long>
  categoryId: long

BookSummaryResponse             (used in search lists)
  bookId: long
  isbn: String
  title: String
  authors: List<String>
  categoryName: String
  availableCopies: int
  totalCopies: int

BookDetailResponse              (single book)
  bookId: long
  isbn: String
  title: String
  edition: String
  publisher: String
  publicationYear: int
  authors: List<AuthorResponse>
  category: CategoryResponse
  availableCopies: int
  totalCopies: int

CreateAuthorRequest
  name: String

AuthorResponse
  authorId: long
  name: String

CreateCategoryRequest
  name: String

CategoryResponse
  categoryId: long
  name: String

LOANS (LoanController)
----------------------
CreateLoanRequest
  bookId: long                  (student comes from the session, copy chosen by the system)

ReturnLoanRequest
  copyCondition: CopyCondition
  damageFineAmount: decimal     (optional, only used when the copy is returned damaged)

LoanResponse                    (student view)
  loanId: long
  bookTitle: String
  status: LoanStatus
  requestedOn: Date
  pickupBy: Date
  issuedOn: Date
  dueOn: Date
  returnedOn: Date
  renewalCount: int

LoanDetailResponse              (staff view)
  loanId: long
  studentId: long
  studentName: String
  studentNumber: String
  bookTitle: String
  copyId: long
  copyBarcode: String
  status: LoanStatus
  requestedOn: Date
  pickupBy: Date
  issuedOn: Date
  dueOn: Date
  returnedOn: Date
  renewalCount: int
  issuedByStaffName: String
  receivedByStaffName: String

PAYMENTS (PaymentController)
----------------------------
PayFineRequest
  amount: decimal               (optional, empty means pay the full outstanding amount)

PaymentResponse
  paymentId: long
  fineId: long
  amount: decimal
  paidOn: Date
  reference: String
  fineStatus: FineStatus        (status of the fine after this payment)

COMMON
------
ErrorResponse
  timestamp: DateTime
  status: int
  error: String
  message: String
  path: String
  fieldErrors: List<FieldErrorResponse>   (filled for validation errors only)

FieldErrorResponse
  field: String
  message: String

PageResponse<T>
  content: List<T>
  page: int
  size: int
  totalElements: long
  totalPages: int
